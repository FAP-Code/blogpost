# Sources

Live bibliography for the Ghana Big Push research project. Every entry has an access date. This
file grows through every phase — Phase 1 below reflects the initial systematic portal check;
later phases add specific documents (individual budget PDFs, IMF country reports, etc.) as they're
pulled into `data/raw/` and `references/`.

**Access date for all Phase 1 entries below: 2026-08-02**, via web search (not yet direct portal
scraping — that begins in Phase 2). Treat every URL as needing a live re-check before it's used
as a cited data point in the final report, since some are aggregator/news summaries of the
underlying primary document rather than the primary document itself.

## Prior/comparator programmes (for the comparative section)

- **Sinohydro Bauxite Barter Arrangement (2018– )**: $2bn total commitment, barter (bauxite for
  infrastructure, no cash), first tranche ~$646–649m financing 442km of roads across all 16
  regions. Directly structurally comparable to Big Push (nationwide road programme, phased
  tranches) and useful as a "what happened last time" baseline — including its own controversies
  (environmental criticism of bauxite mining, a Minority MP calling the deal "a fiasco" that
  should be terminated). Sources: [Pulse Ghana](https://www.pulse.com.gh/story/heres-what-you-need-to-know-about-the-dollar2-billion-sinohydro-deal-2024081311201171642), [China-Global South Project](https://chinaglobalsouth.com/analysis/ghana-commissions-first-roads-built-under-controversial-bauxite-deal/), [DennisLawNews](https://dennislawnews.com/article/sinohydro-road-project-a-fiasco--contract-should-be-terminated---agbodza)
- **National Highways Development Project** — noted to exist (Wikipedia entry found) but not yet
  researched in depth; Phase 2 task.
- **African peer comparators**: no single programme found sharing the "Big Push" name and a
  directly comparable nationwide-roads structure. Closest structural analogs: Kenya/Ethiopia's
  infrastructure-led growth strategies and the LAPSSET corridor (Kenya–Ethiopia–South Sudan);
  Nigeria's Lekki Deep Sea Port / Lagos–Ibadan rail. The comparative section will likely lean more
  on the academic "big push" development-economics literature (Rosenstein-Rodan; Sachs-era African
  applications) than on a single named peer programme — flagged honestly rather than forcing a
  false equivalence.

  no updates needed. **This is the primary boundary source** for choropleth mapping.

  available. Cross-check against HDX.
